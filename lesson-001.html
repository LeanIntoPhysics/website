What Is a Physical State?

The question

What must be true of a description of the world for it to support a prediction?

No particles, forces or coordinates yet. We build physics from the bottom up, with the benefit of knowing where four hundred years of work eventually led.

1.1A box with two buttons

Imagine a sealed box with two buttons and a display. Press a and the display shows 0. Press b and it shows 1.

We can write down exactly what the experiment warrants: two outputs, O = {0, 1}; two interventions, I = {a, b}; and the behaviour a ↦ 0, b ↦ 1. That is enough to predict the display after either button.

But have we described the box’s physical state? Not necessarily. Inside could be two redundant computers, a mechanical toggle, or a tiny person changing the display. The outside behaviour can’t tell them apart.

A description sufficient for a particular prediction need not describe everything physically present.

1.2State is relative to a model

New math · Equivalence relation
New mathM.01

Equivalence relation

A relation that is reflexive, symmetric and transitive. It splits a set into non-overlapping classes. The set of classes is the quotient, written S/~.

Observations induce a quotient of the state space.

Now the question that makes this physics rather than set theory: can two states that look identical now behave differently later?

1.3Dynamics changes what we must distinguish

Give the box a button marked next.1 Pressing it moves the box to a new state by a fixed rule: 0 goes to 1, and every other state goes to 2.

Note 1

1Throughout, a press is one application of the rule. In a game loop it is a tick.

Note 2

2Try 1 against 3, then 0 against 2. Within two presses every run reaches state 2 and stays there.

States 0 and 2 show the same display now, and different displays after one press. To predict the future, parity is not enough.

States 1 and 3 are the opposite case. They are different internal states, yet they produce the same display at every press, forever.

This suggests a stronger equivalence. Two states are predictively equivalent when they produce identical observable histories:

s ≈ t  ⇔  ∀ n ∈ ℕ,  o(fn(s)) = o(fn(t))(1.2)

Under ≈ the four internal states fall into three classes: {0}, {2} and {1, 3}. Not two, which is what the display shows now, and not four, which is what the box contains, but three: exactly what you need to predict every future display.

A useful state description keeps exactly enough information to predict the observations we care about.

Statisticians call this a sufficient statistic; computer scientists will recognise automaton minimisation. It assumes deterministic dynamics, a fixed observable and no other interventions. We will relax all three.

1.5Three things never to conflate

Table 1.2 Reality, model and observation.
ConceptMeaning
Physical realityWhatever actually exists and happens, independent of our description
Model stateThe information a particular theory assigns to describe a situation
ObservationThe result of a specified measurement or interaction

In some classical theories we may treat the model state as fully specifying the system. In quantum mechanics, identifying the state with a complete description of an individual system becomes subtle and depends on interpretation. In statistical mechanics we routinely use states that deliberately discard microscopic information. Keeping the three apart is how we will understand how theories relate.

Two objects whose toString output is equal can still behave differently after the next method call. toString is a display. Key a cache on it and you have treated two objects as one state because they look the same now. Programming-language theory calls the stronger notion contextual equivalence: two programs are equivalent when no surrounding context can tell them apart. That is ≈, with contexts in place of presses.

Two customers can have identical dashboards today, same plan and same usage, and one churns next month. A metric that matches now is ~, not ≈. Ask of any dashboard: what is the smallest description that predicts the thing I actually care about?

The type hole

We have defined what a state is, but not which states are possible, or which transitions happen.

⊢ ?_ : which states are possible
⊢ ?_ : which transitions happen

State 3 is in our model, but nothing reaches it: is it a possible state of the box, or bookkeeping? And we can write down any rule we like; nature doesn’t promise to follow it. An allowed process need not happen. That distinction is lesson 003. First, the question raised by states 1 and 3.

Checkpoint

States 1 and 3 are internally distinct, and no experiment with this box can ever distinguish them. Are they two different physical states, or one physical state described twice?

where this goes

There is no assumption-free answer. The choice leads to one of the deepest ideas in modern physics, the difference between physical identity and representational redundancy, and eventually to gauge theory. That is lesson 002.
